# Hand off Council work

Summarize objective, decisions, exact changes, actual checks, independent review
and unfinished work. Separate local files, commits, GitHub, staging, production
and other self-hosted installations. A build or unpushed file is not deployed.

Preserve dirty work and note ownership where known. Include safe commands and
source pointers without credentials, wallet secrets or private conversations.
If useful, save a dated handoff under docs/handoffs/ and link it. Identify open
decisions and next steps. Do not commit/push/deploy just to end the session;
review and release-specific approval gates still apply.
