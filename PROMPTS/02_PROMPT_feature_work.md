# Build a Council feature

Feature: [outcome]. Read related decisions and implementation. Map affected
web/native/hosted paths, contracts, permissions and persistence. State acceptance
criteria, compatibility, costs, relevant tests and rollback/disable strategy.
Ask about genuinely missing product decisions.

Implement within scope using existing patterns. Agent tools need schemas,
runtime boundaries, permissions, bounded results, cancellation and provenance.
Shared-state changes need dispute, revision, continuation and failure coverage.
Do not introduce unrelated features or hidden account/billing requirements.

Run relevant checks and update capability/user docs. Obtain independent review
of the actual diff and address findings before staging. Report evidence and
limitations. Feature implementation does not grant production release approval.
