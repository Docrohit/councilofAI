# Independent Council review

Target: [diff/files/revision]. Review as a different agent from the implementer.
Read AGENTS.md, requested outcome and actual changes. Do not edit the work
unless separately assigned a follow-up fix.

Check correctness, ownership, permissions, recovery, budgets and interfaces.
Prioritize misleading claims, lost objections, invented tool outcomes and false
completed status. For docs verify source accuracy, current/planned labels,
links, secret handling and consistency with the owner's decisions.

Give each finding a severity, exact location, trigger, impact and actionable
correction/test. Distinguish reproduced defects from source-level risks. Report
bounded checks actually run. Return findings or state none found, with review
scope and remaining gaps. Record the reviewed revision/diff. Passing review is
a staging prerequisite, not production approval or universal correctness proof.
