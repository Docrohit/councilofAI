Adapted from the Saas2point0 context workflow on 2026-09-23; see README.md here.

Verify Council's repository/status/remotes and detect the six root context
files. Preserve existing content and user edits. Inspect actual dependencies,
source, tests, deployment and docs. Discover repositories within the project
and trace three real request paths; do not invent clean architectural layers.

Reuse docs/PLANNING_DECISIONS.md and prior owner answers. Default to option c
for technical questions: inspect code, show findings and flag uncertainty.
Ask remaining questions individually across team/process, architecture, plans,
debt, deployment, server operations, vision, vocabulary and anything else.
Allow answer, skip or code-inspection options. Do not invent historical reasons
for stack choices or force decisions on deferred prices/targets.

Draft AGENTS.md, product_theory.md, deploy_rules.md, server_info.md,
goal_vision_bestcase.md and business_vocabulary.md, plus a documentation index
and relevant prompts. Distinguish current, confirmed future and proposed states.
Validate source claims/links and obtain independent review. Present the draft
for owner feedback. No runtime changes, push or deployment are implied.
